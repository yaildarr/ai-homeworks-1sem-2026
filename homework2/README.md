# Домашняя работа 2

Рекуррентная нейросеть на PyTorch для предсказания следующего слова по тексту из `saltan.txt`.

Запуск из корня проекта:

```bash
python3 -m pip install -r homework2/requirements.txt
python3 homework2/homework2.py
```

Текст читается в кодировке Windows-1251. Модель обучается 20 эпох с контекстом из 25 слов и выводит предсказание следующего слова. Во время обучения печатаются потери и точность на обучающих примерах.

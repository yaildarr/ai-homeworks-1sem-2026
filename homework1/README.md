# ДЗ 1. Полносвязная нейронная сеть

Классификация рукописных цифр MNIST. Сеть и обратное распространение реализованы вручную на NumPy.

- Вход: 784 пикселя (28 × 28), значения нормализуются в диапазон [0, 1].
- Скрытый полносвязный слой: 128 нейронов, активация **ReLU**.
- Выходной полносвязный слой: 10 классов, активация **Softmax**.
- Функция потерь: средняя **категориальная кросс-энтропия**.
- Обучение: SGD по мини-батчам, перемешивание данных перед каждой эпохой.
- Разделение: 55 000 обучающих, 5 000 валидационных и 10 000 тестовых примеров.

## Запуск

Нужен Python 3.9 или новее. Из корня проекта:

```bash
python3 -m pip install -r homework1/requirements.txt
python3 homework1/main.py
```

В PyCharm можно запустить файл `homework1/main.py` кнопкой Run. Зависимости должны быть установлены в выбранном интерпретаторе проекта. Пути к данным и результатам определяются относительно файла, поэтому рабочая папка запуска не важна.

При первом запуске MNIST скачивается в `homework1/data/mnist.npz`; далее используется локальная копия. Это тот же архив, который загружает `tensorflow.keras.datasets.mnist`, поэтому TensorFlow для решения не нужен.

После 10 эпох программа печатает метрики каждой эпохи и итоговые test loss / accuracy, сохраняет результаты и открывает окно с двумя графиками. Если IDE перехватывает Matplotlib, графики появятся в её панели Plots. Закройте окно графиков, чтобы завершить программу.

- `outputs/training_curves.png` — графики loss и accuracy для обучения и валидации.
- `outputs/metrics.json` — параметры запуска, история метрик и итоговая оценка на тесте.

Параметры можно изменить:

```bash
python3 homework1/main.py --epochs 15 --batch-size 128 --lr 0.1
```

Для запуска без графического интерфейса (PNG всё равно сохраняется):

```bash
python3 homework1/main.py --no-show
```

## Как работает обратное распространение

Для батча `X` размера `(N, 784)`:

```text
hidden = ReLU(X @ W1 + b1)               # (N, 128)
logits = hidden @ W2 + b2                # (N, 10)
output = Softmax(logits)                 # (N, 10)
loss = -mean(log(output[i, y[i]]))

delta_output = (output - one_hot(y)) / N
delta_hidden = (delta_output @ W2.T) * (hidden > 0)
dW2 = hidden.T @ delta_output
dW1 = X.T @ delta_hidden
db2 = sum(delta_output, axis=0)
db1 = sum(delta_hidden, axis=0)
```

Все параметры обновляются по формуле `parameter -= lr * gradient`. Softmax и кросс-энтропия вычисляются со сдвигом logits для численной устойчивости. Валидационная и тестовая выборки не участвуют в обновлении весов.
